# Fake News Detection using LSTM

## Objective
To classify news text as Fake News or Real News using a sequential deep learning model.

## Technologies Used
- Python
- Google Colab
- TensorFlow and Keras
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn

## Methodology
1. Load and prepare the labelled text dataset.
2. Clean and preprocess the text.
3. Tokenize the text and apply padding.
4. Split the data into training and testing sets.
5. Build and train an LSTM model.
6. Evaluate using accuracy, precision, recall, F1 score and a confusion matrix.
7. Predict the class of a new article.

## Model
LSTM (Long Short-Term Memory)

## Dataset Note
This version uses a manually created sample dataset containing 2,000 labelled text records for demonstration. It is not the original Kaggle dataset, and its evaluation results should not be interpreted as real-world performance.

## Result
The model completed training and produced evaluation metrics and a prediction for a new article.

## Future Improvement
Evaluate the model using a genuine, diverse fake-news dataset and test its performance on unseen articles.
